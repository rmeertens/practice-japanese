Printable JLPT Kanji Practice Sheets

Free, printable PDF worksheets for testing kanji recall, one set per JLPT level from N5 (beginner) through N1 (advanced). Each sheet has one empty box per kanji with its English meaning printed above — the kanji itself is not shown, so you can use the sheet to test whether you can write it from memory. A matching answer key (in the same order, with the kanji filled in) is available for each level to check your work. Kanji are ordered to match the Benkyo app for N5/N4, and by Japanese school grade level (simplest first) for N3–N1.
